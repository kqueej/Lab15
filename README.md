## 1
JSON текстовый формат хранения структурированных данных, для обмена информацией

## 2
Serialize преобразует объект в JSON-строку, а Deserialize восстанавливает объект из JSON-строки

## 3
Результат имеет тип string, потому что JSON представляет собой текст

## 4
JSON сохраняют через File.WriteAllText, восстанавливают объект с помощью JsonSerializer.Deserialize

## 5
Да, можно, список объектов преобразуется в JSON-массив, содержащий JSON-объекты

## 6
При некорректном JSON или несовпадении типов данных возникает исключение

## 7
JSON позволяет сохранять данные в файле и восстанавливать их после завершения программы
